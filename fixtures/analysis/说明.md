# 经营分析样例

observations 为 merchant_id 与 month 对应的经营观测，revision 是修订序号，known_at 是入库日。sales 为元，repeat_rate 与 digital_share 为比例，open_days 为实际营业天数，null 表示未知。new_merchants 与历史采用相同特征名称；training_cutoff 为训练资料截止日期，previous_release 可以引用先前发布编号。

日期采用 ISO 8601；样例完全由固定种子生成，不含真实个人、机构或设备资料。字段缺省与数值零的含义不同。原有 fixtures/demo.json 仍用于既有业务流程。
